# HireSmart WordPress Theme

AI-Powered Job Portal and Career Builder with Advanced ATS landing page theme for WordPress.

## Description

HireSmart is a modern, responsive WordPress theme designed for showcasing an AI-powered job portal and career builder platform. The theme features a comprehensive landing page with sections for features, use cases, differentiators, and pricing.

## Features

- **Modern Design**: Clean, professional design with smooth animations
- **Responsive**: Fully responsive layout that works on all devices
- **AI-Focused**: Designed to highlight AI and machine learning capabilities
- **Sections Include**:
  - Hero section with clear call-to-action
  - Features showcase with 6 key capabilities
  - Use cases for job seekers, employers, and agencies
  - Differentiators section explaining competitive advantages
  - Pricing plans with transparent comparison
  - Call-to-action section
  - Comprehensive footer with links

## Installation

1. Upload the theme folder to `/wp-content/themes/`
2. Activate the theme through the 'Appearance' menu in WordPress
3. The landing page will be displayed as your homepage

## Theme Structure


## Customization

### Colors
Primary colors can be customized in `style.css` using CSS variables:
- `--primary-color`: Main brand color
- `--secondary-color`: Secondary brand color
- `--accent-color`: Accent color for highlights

### Content
Edit `index.php` to modify:
- Features list
- Use cases
- Pricing plans
- Differentiators

# HireSmart - AI-Powered Job Portal

## Project Overview

HireSmart is an AI-powered job portal and career builder with an advanced Applicant Tracking System (ATS). The platform connects job seekers, employers, and recruitment agencies through intelligent neural AI technology.

## Features

### For Job Seekers
- AI-powered job matching based on skills and preferences
- Resume optimization and feedback
- Application tracking with real-time status updates
- Career path recommendations
- Interview preparation resources

### For Employers
- AI-powered candidate screening and ranking
- Automated interview scheduling
- Collaborative hiring tools for teams
- Custom branded career pages
- Comprehensive analytics and reporting

### For Recruitment Agencies
- Multi-client management dashboard
- Talent pool and candidate database management
- Commission tracking and invoicing
- White-label solutions
- Dedicated account management

## What Makes HireSmart Different

1. **Neural AI Technology**: Context-aware matching beyond simple keywords
2. **95% Faster Matching**: Instant processing of thousands of profiles
3. **Unified Platform**: All stakeholders work seamlessly together
4. **Success Prediction**: AI predicts candidate success rates
5. **Real-Time Insights**: Full visibility with detailed analytics
6. **Scalable Solution**: From startups to enterprises

## WordPress Theme

This repository contains the WordPress theme for the HireSmart landing page. The theme is designed to showcase the platform's features, use cases, pricing, and competitive advantages.

### Installation

1. Clone this repository
2. Copy the theme files to your WordPress installation's `wp-content/themes/` directory
3. Activate the theme in WordPress admin panel
4. The landing page will be displayed as your homepage

## Technology Stack

- WordPress Theme
- HTML5
- CSS3 (with CSS Variables)
- JavaScript (ES6+)
- Responsive Design
- Intersection Observer API for animations

## Development

To modify the theme:

1. Edit `style.css` for styling changes
2. Edit `index.php` for content and structure
3. Edit `js/main.js` for interactive features
4. Use `functions.php` for WordPress-specific functionality

╔════════════════════════════════════════════════════════════════════════════════╗
║                     Session Sharing Configuration                               ║
╚════════════════════════════════════════════════════════════════════════════════╝

  Both domains use shared cookies via wp-config.php:
  
  ┌────────────────────────────────────────────────────────┐
  │  define('COOKIE_DOMAIN', '.startupstreet.in');        │  ← Note the dot!
  │  define('AUTH_KEY', 'same-key-on-both-domains');      │
  │  define('SECURE_AUTH_KEY', 'same-key');               │
  │  ... (all 8 keys must match)                          │
  └────────────────────────────────────────────────────────┘
  
  Result: User logged in on app-hiresmart stays logged in on hiresmart
